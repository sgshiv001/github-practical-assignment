# Collaborative Development Practical

This repository is used to practise collaborative Git and GitHub workflows. The sample project applies those workflows to a binary heap lab: Heap Sort orders integers, and a priority queue removes the item with the smallest priority number first.

The work is organized so the project implementation can be introduced through a feature branch and pull request. Contributors can use the repository to practise fetching remote changes, pulling updates, pushing a branch, and reviewing a proposed change.
